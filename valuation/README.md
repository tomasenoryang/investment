# A 股估值工具

在本机浏览器输入六位 A 股个股代码，查看滚动市盈率（PE-TTM）和历史估值参考线。

## 启动网页

在项目目录运行 `./run.sh`，脚本会启动服务并打开浏览器。服务已经运行时会直接打开网页。新浏览器的关注列表初始为空，升级保留已保存的关注记录。主列表及左侧目录按基金、黄金、股票分组，分组保存在关注记录中。所有品种均可移出，也可通过查询代码重新加入。基金各有净值和跟踪指数估值两张图。手动刷新网页时同步，切换区间使用已同步的数据，默认近五年。所有图可下载，也可悬停读数或放大查看。


已配置基金的「收益对比」使用基金管理人公布的同日基金收益和合同基准收益，在所选区间的首个共同样本归一至 100。实线为基金，虚线为合同基准，期末差值以百分点表示。各区间按官网实际样本绘制，图中标出起止日期。

指数图的估值分位是当前 PE 在所选区间有效样本中的百分位（小于或等于当前 PE 的比例）。变化原因只比较同时有指数点位和正 PE 的日期。点位除以 PE 是指数盈利的估算，指数调仓、估值计算口径也会影响它。估值与点位来自同一响应的指数共用一个日缓存。港股指数的官方点位单独按代码缓存，基金收益与合同基准成对缓存。打开标签、切换区间和悬停复用已有数据。

已配置基金按所选区间显示指数跟踪率（基金累计收益率 ÷ 实际跟踪指数累计收益率 × 100%）和累计收益差（百分点）。两者采用相同的起止日期；覆盖不足时图上注明实际区间，指数累计收益为零时跟踪率显示为不可计算。指数下跌时保留收益率的正负号。

可选的本机基金资料与补充指数放在被 Git 忽略的 `valuation/.local/`。无本地配置也可启动服务、查询品种并添加关注。
